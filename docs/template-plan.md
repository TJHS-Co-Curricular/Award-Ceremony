# 转为通用模版 · 计划

> 写于 2026-11-22。2026 年颁奖活动已经结束，要把这个项目改成**每年都能用**的模版：
> 每年换主题，奖项编辑、图片导出、电子书继续沿用。
> 这是计划，还没开始动手。每一步做完在这里打勾，并写进 `CHANGELOG.md`。

## 现状

- **已经通用的**：活动名称、名单、照片、导出设计、电子书设置、效果设置都存在 `data/`；
  所有路径集中在 `lib/env.js`（`DATA_DIR` 等），改起来不难。代码里写死的「2026」「表扬大会」只剩几处默认值。
- **绑死在今年的**：
  1. **金色主题**：金色写死在约 15 个文件、90 多处（`display.css`、`control.css`、`guest.css`、`js/fx/*`、`ebook.js`、`record.js` 等）。
  2. **资料只有一份**：`data/` 就是「今年」。决定：每年从空的 `data/` 重新开始，旧的由维护者自己备份（见第 1 步）。

## 原则

- 每一步做完，**用今年的资料跑一遍，输出要和 1.62 完全一样**（大屏截图、导出图片、电子书逐像素对比）。
- 防泄露规则不变（`publicView()`、`/media/photo` 的检查）。
- `data/` 的文件格式不改：往年备份的 `data/` 放回来照样能打开。
- 每步一个版本，分开提交，出问题能退回。

**不动的**：控制端（`css/control.css` 65、`control.html` 11、`js/control/*` 其它）是操作界面，不是给观众看的，维持金色；
诊断框 `diag.js`、二维码 `qr.js`、输出页外壳的黑底 `display-shell.html` 也不动。

### 做法

- **设定放哪里**：加进现有的效果设定（`lib/fx.js` 的 `SCHEMA`，新开一组「主题」，`global` = 所有屏幕一样）。
  这样存档（`data/fx.json`）、推给大屏（`publicView().fx`）、控制端表单都不用另写；只要 `SCHEMA` 多支持一种 `type: 'color'`（颜色选择器）。
- **主题颜色**（先这几个）：主色（现在的金 `#d9b25f`）、亮色（`#f7e2a6`）、暗色（`#9a7330`）、背景（`#07060c`）、文字（`#f6f1e4`）、次要文字（`#b9ad92`）。
  电子书另外三个：纸张（`#fbf8f1`）、文字、装饰色。
- **特效不逐个配色，改用「色相平移」**：特效里那串暖黄色照旧写着，画之前按「主题主色的色相 − 金色的色相」整体转一下颜色。
  主色是金色时转 0 度 = **和现在完全一样**；换成蓝色，星系、光河、闪光、光点就一起变蓝，亮暗层次不变。
- 大屏 CSS 里直接写的 `rgba(217,178,95,.3)` 改成 `rgb(var(--gold-rgb) / .3)`，`fxconf.js` 的 `fxUpdate()` 设这些变量。

### 分版本

- [x] **2.1 大屏 + 嘉宾页**（①⑥）：颜色全部变成 CSS 变量，`SCHEMA` 加「主题」组和 `color` 类型，控制端「效果控制」可以改颜色、即时预览。
      → 1.63（2026-11-22）。色相平移在 `public/js/shared/theme.js`（`themeApply()`，`TH_VARS` = 变量 → 色系）；设定 `thMain / thHi / thLo / thBg`。
      2.2 / 2.3 的特效、canvas 要跟主题走时，用同一套 `thMap()` 转颜色。
- [x] **2.2 特效 + 导出影片**（②③）：色相平移；`record.js` 改读同一组变量。
      → 1.64（2026-11-22）。特效用 `thC()` / `thGl()`（`shared/theme.js`，worker 里也 importScripts）；预先画好的光点在重建时按主色重画；
      `record.js` 用 `recV()` / `recRgb()` 读 CSS 变量。默认金色时 5 种导出图片和 1.63 逐字节相同。
- [x] **2.3 图片导出 + 电子书**（④⑤）：默认背景、光晕、`EB_C` 跟着主题走；主题导出 / 导入成一个文件，内置几个主题（金色、银蓝、红色……）。
      → 1.65（2026-11-22）。控制端用 `thUse(fx.all)`（`exEnsure()` 读）+ `thC()`；电子书 `EB_C0` → `ebTheme()` → `EB_C`。
      图片导出设计里用户自己选的颜色（字色、团体相框色、团体底色）**不跟主题**，每年在「图片导出」自己改（维护者定 2026-11-22）。
      内置主题 `TH_PRESETS`（`shared/theme.js`）；主题文件中文字段：类型、名称、主色、亮色、暗色、背景。
- [x] **2.4 大会背景：图片 / OBS 影片垫底**（维护者定 2026-11-22，排在 2.2 之后）
      → 1.66（2026-11-22）。效果 `bgMode`（fx / image / clear，可按屏幕设），放在自己的一组「大会背景」，不在「待机画面背景」里。
      大屏 `js/display/bgimg.js`（canvas `#bgimg`，CSS class `bg-image` / `bg-clear`）；图片 `data/backgrounds/bg-all.jpg`、`bg-<屏幕名 hex>.jpg`，
      `/media/bg?s=&k=`；外壳 `display-shell.html` 透明时也透明。「垫底影片」不另加选项：原有的「底层背景」（渐层 + 浮尘）/「待机背景」导出就是。
  - 背景有三种，在「效果控制 → 待机画面背景」选：
    - **程序画的**（现在的星系 / 光河，保留当默认）
    - **背景图片**：控制端上传，**每个屏幕各一张**（主屏 4096×1280、副屏 1920×1080 比例差很多，共用一张会被裁切）；
      存 `data/backgrounds/<屏幕名>.jpg`，没有单独上传的屏幕用「所有屏幕」那一张，按比例铺满（cover）。
      ⚠ 画进 canvas，不用 `<img>`（OBS 内置浏览器会把原图留在显存）；浮尘、揭晓闪光照样叠在上面。
    - **透明**（给 OBS 垫影片）：输出页背景透明，影片放在 OBS 的「媒体源」里垫在下面循环播放，网页只负责文字和名字卡。
      影片不在网页里播：网页播影片会让 OBS 显存越用越多（AMD 核显已知问题）。
  - 背景图片、透明这两种也要能用在：大会背景（揭晓时的底层），不只是待机画面。
  - 「导出影片」加一个选项：导出成「垫底影片」（只有背景 + 浮尘，没有文字），直接给 OBS 媒体源用。
  - OBS 场景导出（`lib/obs.js`）：选「透明」时，场景里自动多一个媒体源（影片路径由用户填）放在浏览器来源下面。
  - 背景图片是公开的东西（观众本来就看得到），但仍然经 `/media/…` + 输出页密钥给，不放 `public/`。
  - 检查：没上传图片、没选透明时，画面和改动前一样。

- 每一版都检查：**默认主题（金色）的大屏截图、导出图片、电子书和 1.62 逐像素一样**；再换一个颜色截图看效果。
